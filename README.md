# 练伴

一个适配手机浏览器的健身打卡网页，支持每日打卡、自然月统计、按日期管理的计划清单、饮食照片日记、体重趋势和本地数据保存。

## 演示账号

支持 `yqq`、`ybb`、`zck` 三个演示账号。使用提供给账号持有人的最新密码。

## 本次更新

- 一天只能新增一条体重记录；单条记录仅显示点，多条记录按日期绘制折线。
- 计划可以按日期新增、编辑及勾选完成，旧版当前计划会迁入清单。
- 底部导航为首页、打卡、计划、饮食、我的；排行在“我的”内。
- 饮食支持照片、名称、餐次、时间、手动热量、备注，按天浏览、编辑及删除。
- 照片在本地压缩后保存，同一浏览器的多个页面通过 storage 事件更新。

## 运行

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据说明

当前为纯前端演示版，账号资料和训练数据按账号保存在当前浏览器的 `localStorage` 中，不会跨设备同步。账号密码仅用于演示，不应用作真实敏感密码。

跨手机同步待接入云端服务；GitHub Pages 本身不提供数据库或服务端登录。创建 Supabase 项目后，需要接入真实身份验证、按用户限制数据读取权限以及实时订阅，再迁移本地数据。

## 验证

`tests/smoke.cjs` 使用 Playwright 在隔离的浏览器上下文中检查关键交互，不写入线上数据。设置 `PLAYWRIGHT_MODULE` 为 Playwright 模块路径，`CHROME_PATH` 为本机 Chrome 路径，然后运行 `node tests/smoke.cjs`。截图输出到未提交的 `.verification/` 目录。
