# 练伴

一个适配手机浏览器的健身打卡网页原型，支持账号登录、每日打卡、历史补签、训练计划、分类统计报表、排行榜、体重记录和本地数据保存。

- `zck` / `20040707`

## 运行

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

例如：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 数据说明

当前为纯前端演示版，账号资料和训练数据按账号保存在当前浏览器的 `localStorage` 中，不会跨设备同步。账号密码仅用于演示，不应用作真实敏感密码。
